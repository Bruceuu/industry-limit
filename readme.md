# Industry Limit

Limit the spawns of industries by industry type.

- **Limit industries by type**
- **Block industry types** you do not want to see founded.

Works with new and existing saves.

---

## Where to find it

**Toolbar button**: the industry icon with a gear, in the mod button area of the main toolbar. It opens the **Industry Limit** window.

**Industry window**: select any industry. The **Industry Limit** card below the game's own cards offers:

| Button | What it does |
|---|---|
| **Limit** | Set a limit on this industry, or leave it at "unlimited" (default) to allow the game to keep spawning it
| **Block type / Allow type** | Stops (or allows again) new industries of this type from being founded. Existing ones stay. |

## New industry spawning
The game's automatic founding is switched off and Industry Limit decides:
  - **When**: At random intervals, on average about once per game year (at least ~5 months apart, at most 3 years).
  - **What**: Only types that are not blocked, and are below the chosen limit.
  - **Where**: Completely random location
  - If nothing qualifies, no industry is founded.

## Recommended
For building and deleting industries manually: [Industry Freedom](https://mod.io/g/transportfever3/m/industry-freedom#description)
For upgrading industries to allow them to be more powerful: [Industry Upgrades](https://mod.io/g/transportfever3/m/industry-upgrades#description)

## Known limitations

- The game does not reveal which industry it will found next. With the custom spawner you decide through blocks and limits instead.
- Text is English only for now (translations welcome).
